# Persona: Administrador do sistema

## Objetivos

- Ter acesso a todos os fluxos do sistema.

## Jornada sugerida na aplicação

1. Acessa a página de entrada e autentica-se como administrador.
2. Visualiza um painel com acesso aos fluxos disponíveis no sistema.
3. Seleciona o fluxo que deseja acompanhar ou executar, como gestão de salas, filmes, sessões ou clientes.
4. Consulta ou realiza as operações disponíveis naquele fluxo.
5. Retorna ao painel para acessar outro fluxo ou encerra a sessão.
